# Level Concept Mindmap Lite

레벨 디자인 컨셉을 5가지 축으로 시각화하고 편집할 수 있는 간단한 마인드맵 웹앱입니다.

[**웹앱 사용하기**](https://renesumin.github.io/LD_Concept_Mindmap_Lite/)

## 주요 기능

- 5가지 축(시대, 장르, 핵심 동사, 공간, 공간 구성 요소)과 75개 단어를 마인드맵으로 시각화
- 노드 텍스트 직접 수정, 하위 노드 추가 및 삭제
- JSON 파일로 작업 세션 저장 및 불러오기
- 전체 마인드맵을 투명 PNG로 내보내기

## 사용 방법

1. 웹앱에 접속합니다.
2. 샘플 JSON을 다운로드하거나 호환되는 JSON 파일을 불러옵니다.
3. 노드를 더블클릭하여 수정하고, 필요한 단어를 추가하거나 삭제합니다.
4. `세션 저장`으로 작업을 보관하거나 `PNG 저장`으로 이미지를 내보냅니다.

AI 단어 생성 기능은 웹앱에 포함되어 있지 않으며, 외부에서 생성한 호환 JSON을 불러오는 방식입니다.

## 로컬 실행
```
npm install
npm run dev
```
